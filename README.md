## 结构与运行

站点由 GitHub Pages 直接提供 HTML、CSS、JavaScript 与 JSON，不需要应用服务器，也不需要先运行前端框架构建才能阅读。

```text
index.html                   总馆入口
404.html                     普通 404 与明确旧地址的兼容入口
modules/index.html           全站馆藏目录
modules/*/                   年鉴、译读、纪要、乐理、远程入口与博物馆专题
guobo-museum/                中国国家博物馆专题（保留既有地址）
modules/*/module.json        模块公开元数据
data/                       跨模块索引与既有数据清单
modules/europa/data/          欧罗巴研究实体与华夏卷数据
shared/                     按页面引用的共享导航、样式与组件
schemas/                    元数据约束
scripts/                    确定性生成、静态验证与浏览器检查
.github/workflows/           持续集成检查
```

各专题保留自己的视觉与数据组织。数据文件、公开元数据和页面入口分工不同：研究数据承载条目内容，`module.json` 描述模块的范围与访问状态，HTML 提供可直接阅读的入口。布索尼正文继续采用现有密码访问方式，公开目录不包含解锁后的材料。

## 检查

总馆、馆藏目录和上方模块表均由 `module.json` 生成，约束和计数口径见 [模块元数据说明](docs/module-catalog.md)。修改元数据后在仓库根目录运行：

```sh
python scripts/build_site_catalog.py
python scripts/build_site_catalog.py --check
python scripts/validate_modules.py
python scripts/check_site.py
node scripts/qa.mjs
python scripts/product_guard.py verify
```

生成器只替换 `BEGIN GENERATED` / `END GENERATED` 标记内部；`--check` 在入口缺失、元数据非法或生成结果过期时返回非零，不写文件。未知内容修订日期使用 `null`；界面修订不覆盖学术内容日期。

各模块的浏览器检查位于 `scripts/smoke_*_browser.py`，使用已有的 Playwright 流程。产品基线只有在明确获得用户视觉批准后才可更新；通过测试不等于获得批准。

## Shao Music Desk

`modules/shao/` 是远程音乐生成服务的静态说明与启动入口，不在 GitHub Pages 内嵌 GPU 任务界面。任务提交、进度、试听和下载在远程服务中进行；浏览器无法可靠探测时，入口状态标为未验证。使用完成后请按实际服务说明处理音频下载与算力实例。
