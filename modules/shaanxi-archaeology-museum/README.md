# 陕西考古博物馆 · 现场图录

这是一个独立于 `qinhan-museum` 的本地静态网站模块，记录一次参观陕西考古博物馆时留下的照片、展签与材料线索。首页只保留四个区块：主题、馆介绍、镇馆之宝、其他文物。

## 内容边界

- 原片保存在 F 盘；网站照片清单包含 521 个文件名，原片未被移动或覆盖。
- 网站只保存本地派生图：方向校正、尺寸转换和轻微锐化；不对现场内容做生成式补足。
- `DSC_3118.JPG`、`DSC_3119.JPG`、`DSC_3121.JPG` 的现场展签明确指向“唐昭容上官氏墓”，因此页面设置“上官婉儿墓”重点专题。
- `DSC_3114.JPG` 是墓志盖与展签的同框照片；网页将其标为展陈记录，不写成墓葬原址照片。
- 其他唐墓、北宋墓葬壁画和器物记录分开编排，不互相借用墓主身份。
- 没有完全辨认的文字不做全文释读；文件序号用于回到原始现场。
- 附带的外部清单只参考条目排版，不作为本馆现场照片的分类依据；本页对象只按现场照片与展签记录归档。

## 目录

- `index.html`：网站入口
- `styles.css`：视觉与响应式布局
- `app.js`：四个区块的数据填充与图片放大
- `data/catalog.json`：精选记录与公开来源
- `data/photo-manifest.json`：F 盘 521 张 JPG 的只读索引
- `review/contact-sheets`：可回看每一批照片范围的接触表，页面“证据索引”可直接打开
- `assets/photos/web`：网站放大图
- `assets/photos/thumbs`：网站缩略图
- `review/contact-sheets`：分批接触表，仅用于素材核对
- `tools`：清单、接触表和派生图生成脚本

## 本地查看

在项目目录运行：

```powershell
python -m http.server 8765
```

然后打开：<http://127.0.0.1:8765/shaanxi-archaeology-museum/>。

直接双击 HTML 也能看静态页面，但照片目录的自动加载和筛选需要通过本地 HTTP 服务打开。
