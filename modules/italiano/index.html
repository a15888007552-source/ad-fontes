La diagnosi · 诊断

三个症状,一个病根

「语法看了忘」「写不出句子」「说不出话」——听起来是三件事,其实是同一件:你所有的学习动作(看课文、看语法表、背单词)都在往识别通道里存货,而考试和真实对话调用的是提取通道。认知科学里这叫提取练习效应:见过一百遍 ≠ 能提取一次。词汇量是你的资产,一年的阅读没有白费——但从今天起,学习动作全部换向。

过去一年(识别通道)

  • 看课文 → 懂了 → 翻页
  • 看语法表 → 「哦原来如此」→ 三天后清零
  • 背单词 → 认得 → 用不出
  • gpt-live 顺着你 → 舒服 → 没长进

这个暑假(提取通道)

  • 每天一篇闭卷写作 → 写错 → 才翻书 → 错句进弹药库
  • 每天30分钟强指令口语 → AI被迫全意语、正常语速、逢错必纠
  • Anki只做句卡 → 中文面→出声说出意语整句才许翻面
  • 每天15分钟影子跟读 → 练口腔肌肉和语调,不管语法

Le regole · 军规

六条军规,违反任何一条计划就废

这套计划由四个课程模块合成,又被一个专门的审校流程拆过一遍——超载的砍了,画饼的删了。剩下的每一条都有理由,别自作主张加练。

先闭卷,再翻书

永远让「想不起来」先发生。默写、造句、写作全部闭卷完成后才许核对。翻着书写出来的句子,大脑不记账。

错误驱动,不预习

语法只在你写错、说错之后才回锅。错句清单(笔误+口误共用一份)是全营最重要的文件,每天早上第一件事就是重写昨天的错句。

语块可以预支

mi piace / mi è piaciuta / mi alzo 这些形态会出现在教学周之前——先当固定语块整句背用,机制到那一周再补。这不是漏洞,是设计,别觉得被糊弄。

到点就停

Anki 到80张停,写作到时停,口语只跑当日指定的那一张卡、绝不叠加。超时不是勤奋,是偷明天的精力。你的短板是收尾,不是开头。

周日全休,失败降负

周日是训练的一部分——大脑在休息时固化语法。周六关卡没过:当场订正+48小时内补测;连续两周没过:砍一半范围重测。永远不许用「加练」惩罚自己。

进步用耳朵确认

每篇作文写完朗读录音;7/25 的1分钟自我介绍是第0号基线录音,每两周回放对比一次。坚持不靠意志力,靠听见自己变强。
