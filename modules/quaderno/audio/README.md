Italian pronunciation recordings
================================

These are AI-generated speech, synthesized locally with Piper 1.8.0 and
the it_IT-paola-medium voice. The voice configuration uses Italian (it)
phonemes. The recordings do not use the browser's default system voice.

Voice model: https://huggingface.co/rhasspy/piper-voices/tree/main/it/it_IT/paola/medium
Model card: https://huggingface.co/rhasspy/piper-voices/blob/main/it/it_IT/paola/medium/MODEL_CARD
Voice dataset (CC0-1.0): https://huggingface.co/datasets/paolapersico1/Voice-Dataset-Italian
Piper engine (GPL-3.0): https://github.com/OHF-Voice/piper1-gpl

Generation: scripts/generate-pronunciation.py. Requires a separately downloaded
model and piper-tts Python environment; neither is shipped as executable Site
code. Settings: length_scale=1.08, model default noise, mono MP3 at 48 kbps.
The manifest maps the exact normalized Italian term to its recording.
Slashes between listed alternatives are spoken as pauses.
