## 强制身份区分

- 簠 `fu`：方形有盖；盨 `xu`：圆角长方有盖；敦 `dun`：浑圆或近球形有盖。
- 方彝 `fangyi`：高体方形、屋顶形盖；不得映射到敦。
- 豆 `dou`：浅盘高柄；量器斗 `dou-measure`：量取容腔与长柄；挹酒斗 `dou-ladle`：长柄舀酒工具。
- 钟 `zhong`：单件乐钟；编钟 `bianzhong`：成组；镈 `bo`：单件平口大钟；编镈 `bianbo`：成组。
- 铙 `nao`：口向上、柄向下；不得画成悬挂的钟。
- 锺 `zhong-wine`：汉代酒器；不得与乐器钟共用图。
- 磬 `qing` / 编磬 `bianqing`：石或玉质；不得表现为青铜钟。
- 铙 `nao` / 编铙 `biannao`：单件类型与编列系统分别表现。
- 车軎 `zhou-shi` / 车辖 `chexia`：轴端套筒与贯穿销键分别表现。
- 铺首 `pushou` / 门环 `menhuan`：兽面环座与独立门环分别点击。

## 集合图生成方法

每类先制作带编号的构图底稿，按固定网格安置该类全部器物的参考轮廓；底稿只作为图像生成参考，不公开。最终集合图需满足：

1. 16:9 横向完整场景，暗色博物馆或考古陈列氛围，保留左侧标题安全区。
2. 右侧/中部器物按两至三层展台组织，不出现透明抠图感、白底图框或开发标签。
3. 每件器物完整可辨，耳、足、流、柄、悬挂构件、刀刃等关键轮廓不得被遮挡。
4. 不在图内生成文字、器名、水印或说明牌。
5. 生成后逐件与底稿核对；器形、数量或位置不一致则重做，不直接接入。
6. 点击区域使用底稿中的同一位置表，`typeId` 不人工二次排序。
