# 宝鸡青铜器用图谱 · 非兵器类型完整性核对

核对口径：以器用类型为单位；本地照片不是纳入门槛；兵器不进入本图谱。跨馆核对只用于补足器型和器例，不修改其他博物馆页面。当前正式展示 98 项，其中青铜类型 96 项，石 / 玉礼乐相邻项 2 项。

## 1. 食器 / 炊器

| 状态 | 类型 |
| --- | --- |
| EXISTING | 鼎、鬲、甗、簋、簠、盨、豆、敦、盂、盆、鍑、釜 |
| ADD | 甑 |

敦的 canonical form 固定为圆腹或近球形、上下合盖；簠与盨承担长方或圆角长方盖器身份。

## 2. 酒器

| 状态 | 类型 |
| --- | --- |
| EXISTING | 爵、角、觚、觯、斝、尊、卣、罍、壶、觥、方彝、瓿、缶 |
| ADD | 卮 |
| MERGE_AS_SYNONYM | 樽 → 尊 |

卮与觯同音但不合并；方彝不作为所有方形盖器的泛称。

## 3. 水器 / 调和器

| 状态 | 类型 |
| --- | --- |
| EXISTING | 盘、匜、盉、鉴、洗 |
| ADD | 鎣 |
| SUBTYPE_ONLY | 铜洗 → 洗 |

跨馆器例：陕西历史博物馆站的伯百父鎣、“兴元”铜洗与双鱼纹铜洗。

## 4. 量器

| 状态 | 类型 |
| --- | --- |
| EXISTING | 升、斗、斛、量、铜量 |
| ADD | 方升、权 |

量器身份须由器形、铭文、容量或重量关系支持；挹酒斗另列于礼仪附属。

## 5. 乐器与礼乐相邻器

| 状态 | 类型 |
| --- | --- |
| EXISTING | 钟、镈、铙、钲、铃、錞于 |
| ENSEMBLE_SYSTEM | 编钟、编镈 |
| ADD | 铎、句鑃、铜鼓 |
| ADJACENT_NON_BRONZE | 磬（石 / 玉）、编磬（石 / 玉或混合编悬） |

跨馆器例：西安博物院站的三件甬钟；陕西历史博物馆站的五祀钟、师丞钟、柞钟与虎钮錞于。编钟、编镈是编列系统，不与单件钟、镈重复解释；磬、编磬进入礼乐场景但不计入青铜类型数。

## 6. 礼仪附属 / 承置 / 取用

| 状态 | 类型 |
| --- | --- |
| EXISTING | 禁、挹酒斗、勺、匕、瓒 |
| ADD | 俎、案、器座 |

豆（食器）≠ 斗（量器）≠ 挹酒斗（长柄挹取器）。

## 7. 生活器具

| 状态 | 类型 |
| --- | --- |
| EXISTING | 镜、灯、炉、熏炉、带钩 |
| ADD | 奁、盒、铜节、漏壶、熨斗、铜镇、行灶 |

跨馆器例：西安博物院站的羊灯、三眼行灶、人形铜镇、凤鸟铜镇、博山熏炉；陕西历史博物馆站的铜虎镇、铜镜、铜灯。动物形铜镇按镇物功能纳入，不并入一般造像。

## 8. 车马器

| 状态 | 类型 |
| --- | --- |
| EXISTING | 当卢、轭饰、车軎、车舆饰 |
| ADD | 衔、镳、銮铃、车辖、盖弓帽、车马泡饰 |

车軎与车辖分别承担轴端套接和限位功能；銮铃属于车马发声构件，不并入礼乐钟铃。

## 9. 建筑铜构件

| 状态 | 类型 |
| --- | --- |
| EXISTING | 龙纹单头齿方筒形铜构件、龙纹铜构件 |
| ADD | 铺首、门环、门钉、铜制建筑饰件 |
| SUBTYPE_ONLY | 套筒形铜构件、建筑连接铜件 → 现有两种构件与铜制建筑饰件按连接部位细分 |

铺首可与门环组合，但兽面衔环结构和独立圆环不重复计型。

## 10. 其他非兵器青铜器具

跨馆器例：西安博物院站的齐郡太守虎符、鲁王虎符与鎏金铜造像；陕西历史博物馆站的贵霜铜币、铜印、铜符牌、交钞铜板和佛菩萨铜造像。虎符虽具有军政调发功能，但本身是凭验器，不是兵器。

## 数据实现状态

- 60 个原类型保留，其中带钩从“其他”移入生活器具；“斗”明确命名为“挹酒斗”；“轴饰”明确为“车軎”。
- 新增 38 个展示项：36 个青铜类型，2 个相邻非青铜礼乐类型。
- 每个展示项具有唯一 visual identity record、唯一场景对象和唯一 canonical asset。
- 铜洗、双耳铜杯、具体钟器、具体铜印与具体币种作为器例或 subtype，不重复增加 canonical type。
