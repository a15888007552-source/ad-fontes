发布建议

如果你要在线上展示，直接把这个目录单独部署到 GitHub Pages 即可；如果要做更完整版本，再把图片和数据一起补进来。

碑与碑文

把书体、刻工、碑阴与题额分开看，先看文字分区，再看结构和笔意，不把不同历史层次混成一层。

墓志与拓本

拓本是版本与传播材料，不等于原石本体。读拓片时要同时追问拓制年代、纸墨与装裱痕迹。

石刻与礼乐

碑林的价值不止在书法，也在礼制、纪念、知识传播和地方文化记忆的交汇处。
